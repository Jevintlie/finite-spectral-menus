# arXiv upload guide — Paper 2, preparation v9

Prepared 8 November 2026. This is an author submission handoff; no submission
has been made by this workflow. GitHub v9 is our preparation version. Your
first arXiv submission will receive its own identifier and arXiv version v1.

1. Download `paper2_algorithmic_arxiv_source_v9.zip` from the v9 GitHub
   release onto the laptop where your browser is running:
   https://github.com/Jevintlie/finite-spectral-menus/releases/tag/v9.
   The PDF there is for comparison; upload the dedicated source ZIP, not the
   complete research bundle. The ZIP already includes the bibliography,
   figure and all required TeX inputs.
2. Sign in or register at https://arxiv.org/user. Use your real author name,
   Jevint Felixciano, and Independent researcher where affiliation is asked.
   Verify your account email. Choose START NEW SUBMISSION and identify
   yourself as an author.
3. Suggested primary category: Mathematics / Optimization and Control
   (`math.OC`). This is a subject-fit recommendation, not an acceptance
   guarantee. If endorsement is requested, follow the emailed instructions.
   You can identify eligible endorsers through related arXiv abstract pages.
   An independent researcher can seek personal endorsement; it is not peer
   review. No endorsement request has been sent on your behalf.
4. Choose CC BY 4.0 (Creative Commons Attribution), the manuscript license
   you already authorized. Review the portal's submission agreement.
5. Upload the source ZIP. Select `main.tex` as the top-level document and
   `pdfLaTeX` as the processor if asked. Run the portal's processing step.
6. Copy the exact title, author, abstract and comments from
   `arxiv_metadata_copy_paste.txt` alongside this guide. Leave journal
   reference, DOI and report number blank: none is assigned to this paper.
   The file contains labels; paste only each field's value. The abstract
   includes basic LaTeX math, as allowed by arXiv.
7. Open the PDF generated by arXiv. Compare its content with the local
   22-page PDF: title/author, equations, figure, tables, appendices, 20
   references, artifact URL, declarations and AI-assistance disclosure.
   Small layout differences can arise from TeX versions; missing content,
   unresolved citations or broken equations need correction before submission.
8. Complete the final review and submit. Save the submission confirmation
   and temporary identifier. A saved draft or successfully compiled PDF is
   not yet a completed submission. Moderation may request changes or alter
   classification. After announcement, add the assigned arXiv link to GitHub.

The portal may present these steps in a different order. If processing fails,
retain the error log so the exact problem can be fixed. Do not change the
category merely to evade an endorsement request.
